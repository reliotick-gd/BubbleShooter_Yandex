PNG-арт шариков-зверят (Вариант 2).

Положи сюда файлы — игра подхватит их автоматически вместо процедурной
отрисовки (AnimalSpriteFactory). Нет файла = рисуется кодом, как раньше,
ничего не ломается.

Имена строго (id -> файл):
  0  cat.png      кот
  1  bear.png     мишка
  2  frog.png     лягушка / зелёный
  3  bunny.png    зайка
  4  fox.png      лиса
  5  chick.png    цыплёнок
  6  panda.png    панда
  7  dog.png      пёсик
  8  rainbow.png  радуга (спецшар)
  9  bomb.png     бомба (спецшар)

Требования к файлу:
- PNG с прозрачным фоном (alpha).
- Квадрат (512x512 или 1024x1024).
- Персонаж/шар занимает ~90% кадра, по центру, минимальные поля.
- Единый стиль и ракурс у всех 10 (см. промт генерации).

Импорт: можно оставить Texture Type = Default — спрайт создаётся в рантайме
(pivot по центру, pixelsPerUnit = ширина текстуры), масштаб совпадает с
процедурным. Если выставишь Sprite (2D and UI) — тоже ок.
