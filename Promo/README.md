# Промоматериалы для Яндекс Игр

Всё снято с релизной сборки от 1 августа 2026 — с уже поправленным UI (новый порог
широкой раскладки, полноэкранная камера, бустеры с счётчиками). Старые материалы
не годятся: интерфейс с тех пор изменился заметно.

Иконку и обложку делает заказчик отдельно.

## Как это соответствует требованиям площадки

**Не менее 70 % реального геймплея.** На скриншотах подпись занимает 10–13 %
высоты, остальное — живой кадр из игры: геймплея около 88 %. В ролике 21,5 секунды,
из них титульный экран 2,2 с и экран победы 3,2 с — геймплея 16 секунд, то есть 75 %.

**Ничего постороннего в кадре.** Снято релизной сборкой (`CIBuild.BuildPromo`), а не
development-плеером: у последнего в углу висит плашка «Development Build», и кадр с
ней на модерации снимут. Системного интерфейса и элементов самой площадки в кадре нет.

**Локализация.** Русские и английские материалы сняты одним и тем же прогоном с
`-lang ru` / `-lang en`, поэтому доска и раскладка совпадают, отличается только язык.
Подписи на скриншотах переведены.

**Материалы не вводят в заблуждение.** Каждая подпись называет ровно то, что видно
в кадре: механику «три в ряд», бустеры «радуга» и «бомба». Ничего, чего в игре нет,
не обещаем.

**Качество.** PNG без потерь для скриншотов; кадры для видео снимались в JPEG 92 и
кодировались один раз, артефактов сжатия на глаз нет. Затемнений и одноцветных
кадров нет, текст нигде не обрезан.

## Как пересобрать

```bash
# 1. Релизная сборка со съёмочным харнессом (символ PROMO_CAPTURE,
#    задаётся только на эту сборку и в ProjectSettings не пишется)
Unity.exe -batchmode -quit -nographics -projectPath . \
  -executeMethod CozyAnimalTown.EditorTools.CIBuild.BuildPromo

# 2. Скриншот: один кадр за запуск, свой уровень на каждый
./Builds/Promo/BubbleShooter.exe -screen-width 1080 -screen-height 1920 \
  -screen-fullscreen 0 -lang ru -promo out -promomode shot1 -plevel 17

# 3. Кадры для видео
./Builds/Promo/BubbleShooter.exe -screen-width 1080 -screen-height 1920 \
  -screen-fullscreen 0 -lang ru -promo frames -promomode video -plevel 17

# 4. Склейка в MP4. БЕЗ -nographics: кодировщику нужен графический контекст
Unity.exe -batchmode -quit -projectPath . \
  -executeMethod CozyAnimalTown.EditorTools.PromoEncoder.Encode \
  -frames frames -video out/ru_portrait.mp4 -fps 30

# 5. Подписи на скриншотах
python Promo/compose.py
```

Кодек — `UnityEditor.Media.MediaEncoder`, он входит в поставку Unity: ни ffmpeg, ни
Unity Recorder ставить не нужно.

## Почему такие уровни

Уровни подобраны по `Docs/levels_table.csv`: 17, 11 и 21 — шесть рядов, пять-шесть
цветов, препятствия только ледяные. Слизь в кадр не берём: зелёный кругляш с двумя
точками читается как недорисованный ассет, хотя в игре это нормальная механика.

Выстрелы делает не случайный автомат: `PromoCapture` перебирает направления и
выбирает то, которое реально соберёт группу, иначе на видео игрок бы мазал.
Для первого кадра прицел ограничен сектором 55–125°, потому что при пологих углах
пунктир проходит через весь экран и наезжает на пушку.
