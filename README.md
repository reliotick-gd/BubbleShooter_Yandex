# Шарики: Милые Зверята (Bubble Shooter: Cozy Animals) — Яндекс Игры

**Названия по языкам** (обязаны совпадать в игре и на странице каталога):
RU — «Шарики: Милые Зверята» (ключ «Шарики» первым словом — категория и топ-запрос;
«бабл шутер»/«bubble shooter» — жирно в описание страницы), EN — «Bubble Shooter: Cozy Animals».

Уютный bubble shooter для платформы **Яндекс Игры** (Unity 6000.4.7f1, WebGL,
локализация RU/EN по языку платформы). Форк CrazyGames-версии
(`Bubble_shooter_animal_CrazyGames`), геймплей идентичен, платформенный слой
полностью переписан под Yandex Games SDK v2 + Яндекс.Метрика.

**Статус: код готов, компилируется (0 ошибок), страница в консоли Яндекса ещё НЕ создана —
ID счётчика Метрики стоит заглушкой (`window.YM_COUNTER_ID = 0` в шаблоне index.html).**

Полный контекст для работы над проектом (архитектура, монетизация, метрики, чек-листы) —
в **`AGENT_HANDOFF.md`**, читать его первым.

## Как запустить
1. Открыть проект в **Unity 6000.4.7f1**.
2. Открыть сцену `Assets/Scenes/SampleScene.unity` (или любую) и нажать **Play**.

Сцену настраивать руками не нужно: игра целиком собирается из кода в рантайме
(`GameBootstrap` + `[RuntimeInitializeOnLoadMethod]`). В режиме редактирования иерархия
пустая — это нормально.

## Игра
- Веди курсором/пальцем — пунктир показывает траекторию с отскоками; отпускание = выстрел.
- 3+ одинаковых зверя лопаются; отсоединившиеся грозди падают. Цель — убрать всех зверей
  за отведённые выстрелы.
- Препятствия: **лёд** (рикошет, бьётся касанием), **слайм** (липкий, hp 2), **камень**
  (рикошет, сносится только бомбой).
- Бонусы: **радуга** (с 3-го уровня) и **бомба** (с 7-го); при открытии 10 зарядов,
  дальше +1 за rewarded.
- 30 ручных уровней (`Assets/Resources/levels.json`) + бесконечный режим после 30-го.

## Интеграция Яндекс Игр (SDK v2)
`YandexBridge.cs` + `Assets/Plugins/WebGL/YandexGames.jslib` + шаблон
`Assets/WebGLTemplates/YandexGames/`:
- **Interstitial (showFullscreenAdv)** — на переходах: следующий уровень, «Ещё раз»/Restart,
  выход на титул. Не раньше 2-го уровня; **кулдаун 90с наш** (Яндекс частоту сам не режет;
  значение стартовое, крутить по метрикам).
- **Rewarded (showRewardedVideo)** — «Второй шанс» (1 раз на попытку), пополнение
  бомбы/радуги (+1 заряд). Награда только после onRewarded+onClose; на onError игра
  продолжается.
- **Sticky-баннер** — `showBannerAdv()` сразу после init SDK, висит всегда
  (в консоли разработчика включить «управление баннером через API»).
- **Лидерборд** `bbShTablica` (создать в консоли, тип «максимум», счёт = уровень):
  сабмит при каждом сохранении прогресса; экран — кнопка в HUD слева от шестерёнки
  (тёмная таблица в стиле Яндекса: топ-20 + зигзаг + окрестность игрока, свой ряд подсвечен,
  аватарки с фолбэком на букву). Гостям сабмит недоступен — молча пропускается.
- **GameplayAPI** (`start/stop`), **LoadingAPI.ready()** на показе титула,
  облачный сейв через `player.setData/getData` (номер уровня).
- **Звук**: внутриигровой тумблер в настройках (у Яндекса нет платформенного mute) +
  автоглушение при рекламе и сворачивании вкладки (visibilitychange — требование Яндекса).
- **Локализация**: `Loc.cs`, язык из `environment.i18n.lang` (ru/be/kk/uk → RU, иначе EN),
  читается синхронно до постройки UI.

## Аналитика (Яндекс.Метрика)
`Analytics.cs` + `Assets/Plugins/WebGL/Analytics.jslib` → `ym(ID,'reachGoal',name,params)`.
Воронка: session_start → level_start → level_complete/fail (+attempt, +reason, +duration) →
retry/second_chance accepted/declined; майлстоуны уровней, playtime-хартбиты (1/3/5/10/20/30м),
реклама (request/shown/rewarded/error по плейсментам), бонусы, онбординг, подсказки, мьют,
session_end на закрытии вкладки. Полный список — в шапке `Analytics.cs`.
**Перед релизом**: создать счётчик Метрики, вписать ID в `index.html`, завести цели
типа «JavaScript-событие» на каждое имя.

## Билд
WebGL: Brotli, Managed Stripping High, IL2CPP OptimizeSize, Wasm2023 выключен,
шаблон `PROJECT:YandexGames`. Загрузка билда — zip-архив с index.html в корне
(лимит 100 МБ разархивированным; наш билд ~13.5 МБ). Проверять черновик через
режим отладки Яндекса (draft-версия в консоли разработчика).
